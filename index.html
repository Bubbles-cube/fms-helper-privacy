隱私權政策 — FMS 助手（找事件＋看回放）

生效日期：2026-11-05　最後更新：2026-11-06　作者：Bubbles　適用版本：8.12.1 以上

1. 適用範圍

本政策適用於 Chrome 擴充功能「FMS 助手（找事件＋看回放）」（以下稱「本擴充」）。本擴充只在 https://www.chitcfms.com/*（以下稱「FMS」）運作，用來協助使用者找錄影事件與檢視單段回放。

2. 我們是否收集資料

不收集。 本擴充不會把任何資料傳送給作者或任何第三方伺服器，也沒有分析、追蹤、廣告或第三方 SDK。

3. 本機處理的資料類型（不會離開您的裝置）

為了在您的瀏覽器內顯示畫面與加速操作，本擴充會讀取 FMS 頁面上本來就已存在的下列資訊，且只在您的瀏覽器內處理：

資料類型來源用途
車輛代號（Car_Unicode）FMS 頁面／您選取的車輛呼叫 FMS 站方開流 API
車牌號碼FMS 頁面顯示與辨識
攝影機通道編號FMS 頁面選擇鏡頭
錄影清單與時間FMS 頁面產生縮圖、選擇回放段
您點選的影像畫面FMS 串流顯示縮圖／回放

上述資料不會被上傳、備份到雲端、傳給作者、分享或販售。它們只存在於您目前開啟的瀏覽器分頁與本機儲存中。

4. 處理目的

  1. 產生縮圖牆，讓您快速找到事件時間點。
  2. 以本擴充的播放器顯示您選擇的那一段回放。
  3. 記住您的三個顯示開關（即時回放介入／找事件視窗／縮圖牆）與面板位置。

5. 儲存位置與保留期限

儲存位置內容保留期限
chrome.storage.local三個開關（0/1）直到您移除擴充
瀏覽器 IndexedDB（fms-tl-cache）您抓過的縮圖直到您清除或移除擴充
頁面 localStorage面板位置、開關備份直到您清除網站資料

所有資料都只存在您自己的裝置／瀏覽器。我們（作者）沒有任何伺服器，也沒有任何方式存取這些資料。

6. 分享、傳輸與販售

  • 不分享：不提供給任何第三方。
  • 不販售：不販售、不轉移使用者資料。
  • 不跨境傳輸：沒有任何資料離開您的裝置。
  • 唯一的網路請求是您原本在 FMS 上操作時就會產生的站方請求（例如取得錄影清單、開流、取得影像）。這些請求由您的瀏覽器直接送到 FMS 站方與其串流伺服器，不經過作者，也不受本擴充控制。

7. 我們不收集的資料

本擴充不收集、不請求、也不存取：姓名、電子郵件、電話、地址、GPS 位置、健康資料、財務或付款資料、密碼或認證資訊、通訊內容、瀏覽紀錄、使用者活動分析、Cookie 追蹤。

8. 權限說明

權限用途
storage只儲存上述三個開關（0/1），存於本機，不上傳。
網站權限 https://www.chitcfms.com/*只在 FMS 頁面注入，用來讀取頁面上的錄影清單、呼叫 FMS 站方既有的開流 API、顯示輔助介面。不存取其他網站。

本擴充不使用 tabs、activeTab、scripting、cookies、history、webRequest 等權限。

9. 遠端程式碼

沒有。 所有 JavaScript 都在擴充包內（包含已內嵌的 ArtPlayer 5.4.0 與 mpegts.js 1.8.0）。本擴充不含 eval、new Function，也不會從 CDN 或任何遠端網址載入程式碼。

10. 您的控制與刪除方式

  1. 到 chrome://extensions 移除本擴充 → 一併刪除所有本機儲存資料。
  2. 在 Chrome 設定中清除 www.chitcfms.com 的網站資料 → 刪除 localStorage 與 IndexedDB 縮圖快取。
  3. 在 FMS 頁面右下角齒輪（或擴充選單）關閉功能 → 停止處理。

我們無法代您刪除，因為我們從未取得您的資料。

11. 兒童

本擴充為企業內部作業輔助工具，不針對兒童，也不收集任何年齡資料。

12. 政策變更

若本政策有變更，會更新本頁的「最後更新」日期與擴充版本說明。重大變更會在新版本說明中標示。
